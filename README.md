# wc-lite

一个零依赖的命令行小工具，用来统计一个或多个文件的行数、单词数和字符数。

- 纯 Node.js 实现，只使用内置模块，没有任何第三方依赖。
- 需要 Node.js 18 或更高版本（`package.json` 中 `engines.node` 为 `>=18`）。

## 用法

```sh
node bin/wc-lite.js <文件...>
```

可以传入一个或多个文件路径。安装为可执行命令后也可以直接使用 `wc-lite`（`package.json` 的 `bin` 字段指向 `bin/wc-lite.js`）：

```sh
wc-lite <文件...>
```

## 输出格式

每个文件输出一行，各列之间用制表符分隔：

```
<行数>\t<单词数>\t<字符数>\t<文件名>
```

当传入两个或更多文件时，会在最后额外输出一行合计，文件名为 `total`，数值是所有成功读取文件的累加结果。

示例（假设 `a.txt` 内容为 `hello world\nfoo\n`，`b.txt` 内容为 `你好 世界\n`）：

```sh
$ node bin/wc-lite.js a.txt b.txt
2	3	16	a.txt
1	2	6	b.txt
3	5	22	total
```

## 统计规则

- **行数**：换行符（`\n`）的个数。如果最后一行没有以换行符结尾，则不计入，这与 `wc` 的行为一致。
- **单词数**：按空白字符（`/\s+/`）切分后，非空片段的个数。
- **字符数**：按 Unicode 码点计数（使用 `[...text].length`，而不是 `text.length`），因此中文、emoji 等都能被正确计数。文件以 UTF-8 读取。

## 错误处理和退出码

- 读取某个文件失败（文件不存在或是目录）时，会向标准错误输出 `wc-lite: <文件名>: <错误信息>`，然后继续处理其余文件。
- 退出码：
  - `0`：全部成功。
  - `1`：至少有一个文件读取失败。
  - `2`：没有传入任何文件参数（此时向标准错误输出 `Usage: wc-lite <file...>`）。

## 运行测试

测试基于 Node.js 内置的 `node:test`，无需安装依赖：

```sh
node --test
```

或者：

```sh
npm test
```
